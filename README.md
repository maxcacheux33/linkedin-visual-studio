# ATELIER / IMPACT — V3.4

Évolution de la V3.3 avec positionnement du titre à la souris, réglages X/Y, recentrage, sauvegarde des décalages dans les projets JSON et prise en charge des compositions créatives dans les URL Make.

## Installation
Déployer le dossier complet avec Cloudflare Pages (Git ou Wrangler pour activer `functions/api/image.js`). Un simple téléversement statique ne déploie pas la fonction serveur. Tester sur un projet distinct avant de remplacer la version actuelle.

## Utilisation
Dans Studio image, activer « Déplacer le titre », glisser sur le visuel, puis désactiver. Les curseurs horizontal et vertical offrent un réglage précis (-250 à +250 px). « Recentrer » rétablit la position du modèle. Les positions sont conservées dans les projets JSON et les liens Make.

## Limites
Le déplacement concerne le titre, pas tous les calques. Certaines compositions avec titres longs peuvent nécessiter un réglage manuel. Les contrôles de droits des images et les limitations vidéo WebM demeurent inchangés.
